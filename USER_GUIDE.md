# User Guide

## Create an account

Open **Create account**, choose a username with 3–30 valid characters, and create a password with at least 8 characters. After registration, the app signs you in automatically.

## Play Connect Four

1. Optionally change the two player names before the first move.
2. Use the arrow button above a column to drop a piece.
3. Players alternate automatically.
4. The game ends when a player connects four pieces horizontally, vertically, or diagonally, or when the board is full.
5. Select **New game** to reset the board.

## Save a completed match

When signed in, finish a game and select **Save match**. The result, player names, move count, and time are added to your private history.

## Manage match history

Open **Match History** to view saved games. Use **Edit** to correct player names, outcome, move count, or notes. Use **Delete** to remove a record. Use **Add Match** to create a record manually.

## Sign out

Select **Sign out** in the top-right area. Match History is protected and can't be opened while signed out.
